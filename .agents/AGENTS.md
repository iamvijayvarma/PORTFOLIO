# Project Guidelines & Rules

## Automatic Git Stage, Commit & Push Directive
- **Automatic Push to Remote**: Whenever code changes or modifications are made, edited, or committed in this workspace, automatically stage (`git add .`), commit with a descriptive message, and push to the GitHub remote repository (`https://github.com/iamvijayvarma/PORTFOLIO.git`, branch `main`) immediately without requiring user permission or confirmation.
